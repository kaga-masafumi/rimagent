# Base building

- Build the smallest enclosed, roofed room with a real door first; a placed blueprint is not a finished room. Verify frames/blueprints are gone and the room digest reports indoors.
- If material is scarce, use sleeping spots temporarily instead of stalling on a third bed or large room. Reserve wood for shelter, door, campfire, and essential beds.
- Pass explicit `stuff` to every stuff-made build. Use dry-run for large layouts.
- Do not build storage/wealth-heavy expansions while food is below 6 days or the first shelter is incomplete. Missions and major expansions wait until a food buffer, beds, cooking, and a defensible entrance exist.
- Set the rally point inside the finished walls near the single entrance and cover; revisit it after layout changes.
