# 戦闘・治療の観測に基づく手順

戦闘を設定するとき、または戦闘後の振り返りで読む。

## 少数の暴走動物

- 室内待避とドアで接触を避ける案を先に評価する。敵・味方・訪問者の位置、敵の移動、武器の射程、射線、退路を確認する。医療要員や戦闘不可の入植者を前列に出さない。
- `ui.goto`の成功は移動指示の受付。目的地に着いたことではない。短く進めて位置とjobを読み、予定の射撃位置に着いてから攻撃を指示する。
- 到着前に敵が迫った場合は、当初の陣形を完成させることに固執せず、退避・ドア封鎖・最小限の迎撃に切り替える。低い射撃技能の命中を前提にした近距離戦は避ける。
- meleeを指示した場合は接触戦になる。離れた安全位置への移動や射撃の代用として使わない。負傷した医療要員は退避し、健康な戦闘要員で接触を引き受ける案を評価する。

## 治療と復帰

- 負傷を見たら、出血、意識・移動能力、治療の要否、医療担当・薬品・到達可能なベッドを確認する。必要なら医療用ベッド、一時的な担当変更、自己治療を設定する。
- 戦闘が終わり、倒れた人や急変がなければ `maintenance` に移り、医療担当に任せて最高速度で60秒進める。軽傷ごとに低速・数秒の停止を繰り返さない。処置後の自然回復は通常の生活と並行させ、平時の300秒間隔へ戻す。
- 行動範囲を屋内に限定した人物が屋外にいると、自己治療の右クリックが許可範囲外で拒否される場合がある。屋内到着を確認してから指示する。
- 「治療が必要」の警告が消えても、治療中というだけの場合がある。各負傷者の `bleeding == 0` と `needs_tending == false` を確認する。これは止血・処置完了であって、傷の回復完了ではない。
- 徴兵、許可範囲、医療用への転用、仕事優先度の変更前の値を記録し、不要になった一時設定を戻す。感染や再出血は次の監視で再評価する。

## 初回実機試験から得た根拠

暴走イグアナ1匹への対処では、移動完了前に射撃を指示して接近を許し、医療担当が負傷した。退避と迎撃で敵を倒し、負傷した2人の出血を止めることはできたが、無傷の防衛には失敗した。

改善の仮説は、医療担当を前線に出さず、移動の受付と到着を区別して距離・射線を確認すること。次の遭遇で負傷の有無と実際の射撃結果を比較し、一般化しすぎない。
